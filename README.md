# Aurevia Studio — Premium Browser Collection

A coordinated collection of six native Chrome themes and four New Tab extensions.

## Current release candidate: Obsidian

Obsidian is a premium native Chrome theme using matte black, graphite and restrained champagne-gold artwork.

### Install locally
1. Download or clone this repository.
2. Open `chrome://extensions` in Google Chrome.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the repository root (the folder containing `manifest.json`).
5. To remove the theme, use the Remove action on the Extensions page.

Chrome themes are browser visual customisations. They do not replace the New Tab page or provide interactive widgets.

## Obsidian package contents
- `manifest.json` — Chrome theme manifest (theme manifest schema).
- `images/theme_frame.png` — browser frame artwork.
- `images/theme_ntp_background.png` — New Tab background artwork.
