# Obsidian — Aurevia Studio

A premium native Chrome theme using matte black, deep graphite and restrained champagne-gold artwork.

## Install locally

1. Extract the theme package.
2. Open `chrome://extensions` in Google Chrome.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose this folder (the folder containing `manifest.json`).
5. To remove it, open the extension details or select Remove from the Extensions page.

Chrome themes are visual browser customisations. This package does not replace the New Tab page or provide interactive widgets.

## Package contents

- `manifest.json` — Manifest V3 theme definition.
- `images/theme_frame.png` — browser frame artwork.
- `images/theme_ntp_background.png` — New Tab background artwork.
- `artwork-source.png` — original generated artwork source.
