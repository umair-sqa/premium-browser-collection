# Aurevia Studio — Premium Browser Collection

A production-quality monorepo of **six native Chrome themes** and **four New Tab extensions**, published under the Aurevia Studio brand.

## Products

### Native Chrome themes

| Product | Load unpacked directory |
| --- | --- |
| Obsidian | `products/themes/obsidian` |
| Shinobi | `products/themes/shinobi` |
| Aurora | `products/themes/aurora` |
| Nebula | `products/themes/nebula` |
| Dev Terminal | `products/themes/dev-terminal` |
| Noor | `products/themes/noor` |

### New Tab extensions (Manifest V3)

| Product | Load unpacked directory |
| --- | --- |
| Salah & Sun Companion | `products/new-tab/salah-sun` |
| Deep Work | `products/new-tab/deep-work` |
| DevSpace | `products/new-tab/devspace` |
| Cosmos | `products/new-tab/cosmos` |

After `npm run build`, equivalent packages are also available under `dist/themes/<id>` and `dist/extensions/<id>`.

## Quick start

```bash
npm install
npm run validate
npm test
npm run build
```

## Install in Chrome

1. Open `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select a **single product directory** from the tables above (never the monorepo root)
5. For New Tab extensions, open a new tab to verify the dashboard

Themes customise browser colours and images only. Interactive dashboards are provided by the New Tab extensions.

## Repository layout

```text
products/     Themes, New Tab extensions, catalog.json
packages/     Design tokens, shared utils, validation
scripts/      Validate, build, preview generation
tests/        Unit, integration, architecture
docs/         Architecture, privacy, store, roadmap
assets/       Shared brand assets
dist/         Build output (generated)
```

## Scripts

| Command | Purpose |
| --- | --- |
| `npm run lint` | ESLint |
| `npm run typecheck` | JS check via TypeScript |
| `npm test` | Vitest suite |
| `npm run validate` | Catalogue + themes + extensions |
| `npm run build` | Copy validated packages to `dist/` |

ZIP archives are **not** generated by default.
