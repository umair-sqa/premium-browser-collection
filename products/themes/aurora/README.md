# Aurora — Aurevia Studio

Native Chrome theme from the Aurevia Studio Premium Browser Collection.

Northern lights atmosphere with midnight blue, emerald, teal, and violet.

## Install (unpacked theme)

1. Open Chrome and go to `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this directory:

```text
products/themes/aurora
```

Or, after `npm run build`, load:

```text
dist/themes/aurora
```

5. Confirm the theme applies to the browser frame, tabs, and New Tab background.

To remove the theme, use **Remove** on the Extensions page (or install another theme).

## Package contents

- `manifest.json` — Chrome theme manifest (Manifest V3 theme schema)
- `images/theme_frame.png` — browser frame artwork
- `images/theme_ntp_background.png` — New Tab background
- `store/` — store preview graphics

## Notes

Chrome themes customise browser chrome colours and images. They do **not** replace the New Tab page with interactive widgets — use the Aurevia New Tab extensions for dashboards.
