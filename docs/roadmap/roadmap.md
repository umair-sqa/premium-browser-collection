# Roadmap

## Completed in 1.0.0

- Monorepo foundation and catalogue
- Six native themes with original artwork
- Four New Tab extensions with local persistence
- Validation, tests, CI, documentation

## Near-term

- Playwright smoke tests that load each extension in Chromium
- Additional locale formatting options for Salah & Sun
- Optional user-provided custom CSS backgrounds for Deep Work without remote hotlinking risks
- Expanded celestial ephemeris accuracy notes for Cosmos

## Explicitly out of scope for 1.0

- Chrome Web Store publication
- Live GitHub repository APIs requiring tokens
- Hardcoded religious quotations
- Claimed live telescope observations
